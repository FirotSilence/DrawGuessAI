# Contributing

Thank you for helping improve DrawGuessAI.

1. Use Node.js 22 or newer and pnpm 11.
2. Run `pnpm install`, then `pnpm format:check`, `pnpm licenses:check`, `pnpm check`, and the relevant Playwright tests before opening a pull request.
3. Add or update tests for protocol, game-rule, or room-state changes.
4. Add both `zh-CN` and `en` text for interface and prompt-bank changes.
5. Do not commit provider keys, `.dev.vars`, generated replay data, copied game assets, or third-party content without compatible licensing and attribution.

By contributing, you agree that your contribution is licensed under AGPL-3.0.
